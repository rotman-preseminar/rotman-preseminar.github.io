# What is where

```
PreSeminar/
├── index.html            THE PAGE. All visible text lives here (header, guidelines, footer).
│                         Edit freely; no build needed.
├── assets/
│   ├── style.css         Colours, fonts, layout. Brand colours are the first lines of the file.
│   └── app.js            Draws the schedule table and resource lists from data/site.js.
├── data/                 EVERYTHING YOU EDIT REGULARLY. Run the build after changing any of it.
│   ├── site.yml          Title, organizers, default pre-seminar time/room, optional banner.
│   ├── schedule/
│   │   └── 2026-27.yml   One entry per seminar. New year = new file (2027-28.yml).
│   ├── resources.yml     Resource categories + external links.
│   └── site.js           GENERATED by the build. Never edit; commit it.
├── sessions/             Papers and slides, one folder per seminar date.
│   └── 2026-10-16/       Folder name = the date in the schedule.
│       ├── xx_paper.pdf      -> "Paper" button
│       └── xx_discussion.pdf -> "Slides" button
├── resources/            Files for students, one folder per category (only needed for FILES).
│   ├── discussing/       How to discuss a paper
│   ├── examples/         Example discussions
│   └── general/          Anything else
├── schedule.ics          GENERATED by the build ("Add to calendar"). Never edit; commit it.
├── scripts/build.py      Reads data/ + folders, writes site.js and schedule.ics, reports mistakes.
├── MAINTENANCE.md        Short how-to for day-to-day upkeep.
├── README.md             Longer explanation, incl. instructions for other faculty.
├── SITEMAP.md            This file.
├── robots.txt            Asks search engines to stay away (the page also carries a noindex tag).
├── .nojekyll             Tells GitHub to publish the files as they are.
└── EmailOrganization.pdf Private; deliberately kept off GitHub.
```

## Which page section comes from where

| On the page | Comes from |
|---|---|
| Header title, subtitle, year | `data/site.yml` + the year of the next session |
| "Next pre-seminar" box | the next entry in `data/schedule/<year>.yml` |
| Schedule table | `data/schedule/<year>.yml` + files in `sessions/` |
| Year tabs above the table | one tab per file in `data/schedule/` (hidden while there is only one) |
| Paper / Slides buttons | files in `sessions/<date>/`, or `paper_url:` / `slides_url:` in the schedule |
| "Add to calendar" | `schedule.ics`, generated from the schedule |
| Guidelines and Expectations | `index.html` |
| Resources | `data/resources.yml` (links) + files in `resources/<category>/` |
| Footer contacts | `organizers:` in `data/site.yml` |

## Adding something: file or line?

| I want to add… | Where | Build? |
|---|---|---|
| A link for students | a `- category:` item in `data/resources.yml` — no folder, no file | yes |
| A file for students | drop it in `resources/<category>/` | yes |
| A seminar | an entry in `data/schedule/<year>.yml` | yes |
| A paper or discussion slides | drop it in `sessions/<date>/` | yes |
| A paper/slides hosted elsewhere | `paper_url:` / `slides_url:` in the schedule entry | yes |
| A guidelines bullet | a `<li>…</li>` in `index.html` | no |
| A resource category | a new folder under `resources/`, described under `categories:` in `data/resources.yml` | yes |
